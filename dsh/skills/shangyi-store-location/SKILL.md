# 开店与选址主动调研规程

当用户考虑在某处开店、搬店、续租谈判或增设门店时，主动执行以下规程（适用于所有咨询主题，不局限于市场进入剧本）：

## 1. 最小定位提取与主动开查

- 从用户描述提取城市、街道、商圈、商场或具体地址及拟经营业态。只要地点与业态足以启动检索，立即开始公开搜索，不要求用户先提供租金或竞争店名单。
- 缺少必要定位时仅追问最小定位信息；面积未知时可先收集不同面积段的挂牌样本，不因此暂停调研。
- 整次咨询网络检索/抓取预算最多 **16 次**：优先少量高命中率查询与相关原文。若用户已给出具体费用与经营假设，先调用 `mcp__shangyi__business_cost` 输出已列成本的条件测算，不因搜集外围资料拖延已有信息的计算。

## 2. 商铺租金挂牌样本核验

- 用目标地点及邻近街道结合“商铺出租、门面出租、租金、招商”等词调用 `mcp__shangyi__web_search`（及可用时的 `poi_lookup`），再用 `mcp__shangyi__web_fetch` 核对原文。
- 去除同一铺位转载，**严格排除**商铺出售、住宅及不适用该业态的纯写字楼挂牌，严禁把售价或办公租金当作门店租金。
- 逐条记录：地址、面积、楼层、租金原值与计价单位、押付条件、物业费、转让费、其他披露费用、发布日期、抓取日期及来源链接。未披露字段标为“未取得”，绝不当作零。
- **口径红线**：不把挂牌租金当作成交租金，不把周边铺位报价当作目标铺位报价；不同面积、楼层或计价周期的样本不直接混合取均值；一次性现金支出（转让费、押金）与经常性租赁成本分列，不擅自假设免租期、税费或摊销年限。

## 3. 周边候选竞争店铺摸排

- 结合地点、目标业态、同类产品与替代消费检索地图商户页、商场品牌目录、点评与公开门店页；先说明采用的街区或商圈范围，若仅有商圈名则按商圈列候选，不虚构精确米数半径。
- 逐店记录：店名、分店名、地址、业态、公开价格带、营业状态、信息日期与来源，并区分 **直接竞争**、**替代消费** 与 **互补业态**；同名不同分店不得合并。
- 仅在有可靠地图/坐标依据时给出距离（区分直线距离与步行距离）；搜索排名不代表距离，评论数不代表真实客流，品牌存在不代表该商圈确有分店。营业状态无法核实时标为“待核实”。
- 汇总为 **“租赁挂牌样本”** 与 **“已检索到的候选竞争店铺”** 两份清单，不得宣称完整覆盖；关键竞争对手通过 `mcp__shangyi__participant_profile_update` 纳入画像。

## 4. `research_record` 原文登记与 `business_cost` 测算规范

- 抓取到正文后调用 `mcp__shangyi__research_record` 登记租赁与门店字段：
  - 引文必须逐字匹配已抓取正文，字段值保留原文写法；
  - 同一条记录的地址、租金、物业类型与发布日期必须出自页面**同一局部记录**，严禁把列表页不同铺位的文字或页眉其他公告日期拼成一条；
  - 仅凭摘要或抓取失败的网页只能标为未核验线索，严禁伪造登记。
- 调用 `mcp__shangyi__business_cost` 进行租金换算、月成本、盈亏平衡与现金流情景计算：
  - 每次调用只计算一个具体 `scenario`，不同铺位、互斥报价或“续租 vs 搬迁”分别调用；
  - 每项费用显式指定 `treatment`：`cash_expense`（现金费用）、`refundable_deposit`（可退押金，单列资金占用，不推定退款时间）、`opportunity_cost`（机会成本，停业少赚不扣现金）、`noncash_expense`（非现金费用）、`unknown`（性质未知）；
  - 未知金额显式传 `amount: null` 并附 `missing_amount_reason`，未列全费用时声明 `costs_complete: false`；`costs` 不接收收入项，收入与可用现金未知时不传，绝不编造数字。
- 完成公开检索与已知成本测算后，只追问会改变决策的用户私有条件（预算硬上限、房东实际底价、面积硬约束、可接受回本期）。
