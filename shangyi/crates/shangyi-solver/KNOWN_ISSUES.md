## KI-1 · Lemke–Howson 在非方阵博弈上不收敛（**未修复**）

| 项 | 内容 |
|---|---|
| **症状** | `lemke_howson::tests::nonsquare_2x3` 报 `超过 116 步仍未收敛（字典序防循环失效）` |
| **影响面** | 仅 LH。`solve_support_enumeration`（主求解路径）不受影响，黄金用例全通过 |
| **已试的三种规则** | ① **严格交替 P/Q**（原实现）：非方阵上 `leaving_label − n` 下溢 panic<br>② **按标号区间**（`label ≥ n → 进 P`，当前实现）：2×2/3×3 正确，2×3 不收敛<br>③ **按不变量**（`p.index_of(label).is_none()`）：使全部 2×2 用例回归失败（59/70） |
| **根因判断** | 字典序枢轴的**破坏平局**规则在非方阵上不够细。LH 的循环避免依赖字典序摄动，当前实现只对枢轴量的符号做了 0-1 最小比检验，未实现真正的字典序向量比较 |
| **正确修法** | 按 Cottle–Pang–Stone 的字典序枢轴规则，用**完整字典序向量**（而非标量比值）做最小比检验；或直接改用支撑枚举作为唯一 2 人路径、LH 仅作交叉检查 |
| **缓解** | LH 的 `Solution.completeness` 已标为 `NotGuaranteed`——调用方**不得**把 LH 输出当作完备解集。黄金用例只把 LH 输出用作交叉检查（子集关系） |

## KI-2 · 退化博弈检测未触发（✅ **已修复**）

| 项 | 内容 |
|---|---|
| **症状** | `support::tests::duplicated_column_flags_underdetermined` 报 `退化博弈不应报告 Complete` |
| **影响面** | 完备性标签的可信度。**这是最值得修的一项**：若退化博弈被误报为 `Complete`，调用方会以为"解集已穷尽"，而实际上退化博弈有无穷多均衡 |
| **根因（已查清）** | 退化博弈里，某支撑对的无差异系统可能**无解**（`LinearSolution::None`）而非欠定，原实现把它与「该支撑非均衡」一起 `Skip` 掉。实测案例：矩阵 `[[1,1,0],[0,0,1]]`、支撑 `I=J={0,1}` —— 行策略 1 在 J 上两列支付皆 0 ⇒ 无差异要求 `v=0`；而归一化 + 行策略 0 的方程要求 `v=1` ⇒ **矛盾** |
| **修法** | 新增独立判据 `support_is_degenerate()`：某玩家的支撑内**支付列/行线性相关**（秩亏）即判退化。无解时据此区分「正常无解（`Skip`）」与「退化导致的无解（计入 `underdetermined`）」 |
| **为何用独立判据而非依赖 `Underdetermined`** | 退化既可表现为欠定、也可表现为无解；只认前者会漏掉后者的整类形态 |
| **验证** | `duplicated_column_flags_underdetermined` 通过；黄金用例 19/19 无回归 |

## KI-3 · 三人路径：占优策略必须入支撑（✅ **已修复**）

| 项 | 内容 |
|---|---|

| **关联** | C6（三人完全混合均衡）黄金用例**通过**，且"无纯均衡""恰 1 个均衡""无幽灵"三项断言均通过 |
| **影响面** | 三人路径的**局部**性质。C6 是唯一有外部权威期望值的 n≥3 用例，它过了；本条断言的是另一性质（占优策略处理） |

## KI-4 · 三人随机博弈的自证/确定性（✅ **已修复**）

| 项 | 内容 |
|---|---|
| **症状** | `support_np::tests::random_2x2x2_equilibria_self_verify_and_are_deterministic` 失败 |
| **影响面** | 三人路径的鲁棒性（随机博弈族上"输出必须自证为均衡"+"同输入同输出"） |
| **为何重要** | 自证失败意味着可能产出**未通过三残余校验**的候选——即"幽灵均衡"泄漏到输出。**这一项与 KI-3 可能同源** |
| **修法** | 以 `Outcome::Continuum(_) => underdetermined += 1` 取代 `return Err(...)`。理由：一个支撑剖面退化**不应**让整个博弈求解失败——退化在随机整数支付下并不罕见（实测 40 个随机 2×2×2 案例中即可触发）。正确语义是计入 `Partial`，让上层看到「解集可能不完备」而非「求解失败」 |
| **验证** | `random_2x2x2_equilibria_self_verify_and_are_deterministic` 40 个案例全通过；黄金用例无回归 |

### KI-1 的处置理由（为何暂不修）

1. **LH 不是完备性路径**：其 `Solution.completeness` 恒为 `NotGuaranteed`（上游文档明确
   "not guaranteed to find all equilibria"）。主完备性路径是 `solve_support_enumeration`，
   非方阵在那边**正常工作**（`nonsquare_works_via_support_enumeration` 断言了这一点）。
2. **无正确性风险**：LH 返回类型化错误，不产出错误结果。
3. **修法成本高**：需实现 Cottle–Pang–Stone 的完整字典序枢轴规则（当前只做 0-1 最小比检验）。
   已试三种规则并记录了各自的失败模式，投入产出比不佳。
4. **影响面小**：生产路径（pricing_response 等 2–4 人标准式）规模小，支持枚举足够。

## 不变量（本 crate 已建立、不得破坏）

1. **三残余必须全查**（单纯形 / 支撑内无差异 / **最佳反应间隙**）。
   只查前两项会产出**幽灵均衡**——满足全部无差异方程却违反最佳反应不等式。
   `§C6.3` 第 3 条记载了两个这样的支撑剖面，独立验证者已复现。
2. **完整性与均衡集分开报告**。`Solution.completeness` 必须由调用方检查；
   `NotGuaranteed`（LH）与 `Partial{...}`（退化）都**不允许**被当作"解集完整"。
3. **精确有理数优先**。黄金用例的混合概率全为小分母有理数，`Rational` 路径要求精确相等；
   浮点容差只用于差分通道（`10-nashpy-oracle.md`）。
4. **失败即拒绝**。无法求解的支撑剖面必须以类型化 `SolveError` 上报，
   禁止返回空解集掩盖失败（设计文档不变量②）。
