# 为什么单列一类

它们**不在五向扫描里**（见 [[value-net-parts]]），因为它们平时不参与博弈。
但它们可以被某个行动**拉进来**，且一旦进来，支付结构就变了。

星宇事件是典型：一方对另一方施压的能力，并不来自它自己的资源，
而来自它**借用第三方**（向对方的客户发函、向交易所投诉）。
若模型只算双方各自的收益，就会漏掉这条真正起作用的链条——
因为主动方的直接收益（出了一口气）远小于对手的损失（市值蒸发）。

# 怎么建模

1. 通过 [[triple-filter]] 的提议才能被注册进博弈
2. 注册时把引入的第三方写入 `external_actors`
3. 对手的行动作为**新增策略**加入其策略集
4. **必须重解**——注册改变了博弈，旧解集作废

第 4 条容易漏：新策略加进去了但用的是旧均衡，等于分析了两个不同的博弈。
