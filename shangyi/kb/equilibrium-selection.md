# 为什么需要选择

博弈常有多个均衡。均衡本身不告诉你哪一个会发生——那是**选择问题**，
不是求解问题。两者混在一起是本领域最常见的概念混淆。

# 六个判据（商奕的实现）

| 判据 | 看什么 | 是否依赖 LLM |
|---|---|---|
| `risk_dom` | 风险占优 | 否 |
| `stochastic` | 演化动态的随机稳定性 | 否 |
| `learning` | 虚拟对局 / EWA 收敛点 | 否 |
| `behavioral` | QRE + level-k（对手有限理性） | 否 |
| `focal_llm` | 聚点判断（Schelling） | **是** |
| `persona_sim` | persona 群 rollout | **是** |

最后两个依赖 LLM，故其权重必须受回测约束——因为它们的输出
不像前四个那样可复算。

# 但这是个真正困难的问题

各判据常给出**不一致**的偏好。商奕的做法是加权融合 + **分歧告警**：
若某判据最看好的均衡在融合结果里概率很低，报告里显式提示，
让用户知道"这不是共识"。

**权重校准需要样本**。冷启动期权重是未校准先验，报告必须如实标注——
见 [[case-library-calibration]]。不标注的后果是读者以为那些概率有实证依据。
