# 为什么需要它

小店 vs 连锁的常规打法分析常以"连锁财力雄厚"收尾——然后呢？
本页回答"然后"：**优势的条件性**。连锁的优势（标准化、规模采购、
品牌）每一项都附带约束：定价要上报、SKU 要全国统一、服务要按手册。
弱者的活路藏在**对手的约束清单**里，而不是自己的勇气里。

# 弱者策略的四条生路（每条都对应对手的一个包袱）

1. **速度**：连锁改一次价格带要审批周期，你当天就能改——
   在它反应过来之前收割，转移阵地
2. **非标准**：手工、现做、定制——标准化流程覆盖不到的 demand
3. **人情密度**：记住熟客的偏好——连锁的会员系统做不到店员级
4. **局部密度**：只做它"物流不经济"的时段/品类/半径

# 一个容易搞错的地方

**弱者策略的前提是"不与对手的优势正面相遇"**。最常见的死法是
被对手激怒后忘掉自己的约束清单、跟着对手打它最擅长的仗（拼折扣力度）。
`repeated-game` 与 `cashflow-endurance` 提醒你：价格战是它的主场。
本页与那两页配合使用：先算 endurance，再选差异化战场。
