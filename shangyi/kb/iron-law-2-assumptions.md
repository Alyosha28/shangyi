# 这条规则在防什么

模型对"对手的成本结构"这类问题**没有真实信息**，但它会给出一个
看起来合理的数字。若该数字未经确认就进了模型，那么整份分析——
包括那些精确算出的均衡——都建立在一个编造的输入上。

**危险之处在于它看不出来**：精确的求解器会给一个精确的答案，
而答案的错误完全来自那个未经确认的输入。

# 怎么强制（不是靠自觉）

商奕在**类型层与流程层**两处强制：

1. **类型层**：`Param` 的 `source` 字段是必填的枚举
   （`user_confirmed` / `public_data` / `industry_prior` / `assumed`），
   而求解器**拒绝** `assumed` 的参数进入。
2. **流程层**：cp2 的提问件要求每一项都带来源，
   空来源直接被 [`checkpoint` 工具]([[checkpoint-enforcement]]) 拒绝构造。

两层都必要：只有类型层，"用户确认过吗"这件事不会被记录；
只有流程层，一个绕过流程的调用路径仍能把假参数塞进求解器。

# 行业先验要标注

若某个参数只能取行业经验值（例如"社区生鲜毛利率通常在 15–25%"），
那是 `industry_prior`——允许使用，但报告必须标注
**"borrowed，非本对手实证"**。

不标注的后果：读者会把行业均值当成这个具体对手的真实值，
而两者可能差很远。
