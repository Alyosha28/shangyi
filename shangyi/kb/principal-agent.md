# 为什么需要它

你雇人替你做事：店长管门店、代运营管投放、投资经理管仓位、信贷员管批贷。你能看到结果，看不到努力。这时「按结果付钱」看起来最公平——但它有个常被忽略的前提：**结果里混着运气**。

Holmström & Milgrom (1987) 的结论很干脆：**激励强度应该随噪声下降**。噪声越大，「按结果付钱」越接近发彩票：你付的是激励，买到的是随机。

# 机制：结果 = 努力 + 运气

```text
结果 = 努力能解释的部分 + 双方都控制不了的部分
激励强度 ∝ 可控信号 ÷ (可控信号 + 外部噪声)
```

（这是直觉式写法，不是可代入的精确公式；正式模型里的形式取决于效用函数与信息结构。）

假设（仅为说明）：门店月利润在「店长认真」时约 10 万、「混日子」时约 8 万；而商圈客流波动本身能带来上下 3 万的落差。此时努力的价值被噪声盖住了——**纯提成制下，努力带来的增量被噪声淹没，合同实际奖励的是运气**。这就是「多劳多得」退化成「多运气多得」：不是人变懒了，是合同在奖励运气。

反过来，什么时候该把激励调强？条件很具体：

- **噪声低**：结果波动主要来自努力，而不是客流、汇率、政策
- **因果链短**：他的动作能比较直接地改变结果（一个月内看得到，不是三年后才知道）
- **他扛得住波动**：收入里固定部分太低的人不敢接强激励；风险厌恶程度高就必须给风险溢价，强激励的固定成本反而更高

# 多任务：只考核可测的那项，会牺牲不可测的那项

Holmström & Milgrom (1991) 的多任务结论：当一个人同时做几件事，而你只对其中可测的那件付钱，他会把精力搬到那件上，牺牲不可测的那件。

金融上最典型的是**信贷员按放款额提成**：放款量可测，坏账要两三年后才显形。指标一旦只考核量，质量就成了那个不可测项——不是信贷员人品差，是考核结构在奖励它。同理，只考核销售额的加盟店会牺牲服务与复购；只考核短期收益率的投资经理会承担尾部风险（收益可测，风险不可测）。

# 一个容易搞错的地方

**第一，激励不足常被误读成「人不努力」**。先查两件事：噪声是不是比努力效应还大；指标是不是只覆盖了他工作的一部分。这两条都可能让一个很努力的人在你眼里显得没产出。

**第二，「提成一定比固定工资有效率」是错的**。代理人风险偏好很低、或现金约束很紧（这个月就要还贷）时，固定工资反而更有效——强激励在他那里等于逼他替你承担他承担不起的风险，他会要求更高的补偿，或者干脆走人。

**第三，顺序不能反：先甄别再激励**。招进来的人本身不对，激励只会让他更快地把资源用错方向，见 [[adverse-selection|先分清类型，再设计激励]]。

# 在商奕里怎么用

- 先分噪声：把结果的历史波动拆成可控部分与外部部分（敏感性扫描管的是这一步）
- 列多任务清单：把他做的事逐项写下，标哪些可测、哪些不可测，再看现有指标漏了哪项
- 条款建议：固定部分覆盖他的保留效用（BATNA），浮动部分挂在噪声最低、因果链最短的那个指标上
