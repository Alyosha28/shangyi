# 为什么需要它

单期博弈里"互相降价"是占优策略，但同商圈的两家店**下个月还要见面**。
重复博弈把"未来的利润流"变成今天合作的抵押品——
这正是很多商圈长期相安无事的原因：不是老板们道德高，是**不合算**。

# 临界条件（报告里要给出数字的那个）

合作维持的条件大致是：

```text
未来合作收益的现值 > 今天背叛的一次性收益 + 失去未来收益的损失
```

贴现因子 δ（未来收益折算到今天的权重）是关键变量：

- δ 高（有耐心、现金流稳）⇒ 合作容易维持
- δ 低（缺钱、急用现金）⇒ 合作脆弱，对手降价就该警觉它快要撑不住了

`data_needs` 里强调"贴现因子不只是利率"——一个账上只够发两个月
工资的老板，δ 实际上很低，哪怕名义利率是 0。

# 一个容易搞错的地方

**惩罚必须可信才有用**。"他降价我就跟他打到底"——如果打到底
你自己也破产，这句话就是空话，对手知道。可信的惩罚往往是
**对惩罚者代价最小的那种**（如"你降我就只在你引流的那几款上降"），
而不是情绪化的全面战争。评估对手的报复威胁时，先算**它报复的成本**。
