# 它回答什么问题

不是"均衡是什么"，而是**"这个结论有多脆弱"**：
对手成本从 9.9 涨到多少，我的最优选择会变？

这比点估计有用得多。中小企业主真正需要的是**判断的边界**，
而不是一个看起来精确的数。

# 输出（两种情形都要如实）

- **找到翻转区间**：给出夹逼的两点，并说明这是扫描步长的精度
- **未找到翻转**：**必须写明"这是扫描范围内的结论"**，
  不得暗示"该结论稳健"——那是超出证据的主张

后者的措辞很重要：不写清楚，读者会把"我没扫到"读成"不会翻"。

# 与 [[monte-carlo]] 的分工

| | 回答 |
|---|---|
| 蒙特卡洛 | 多个参数同时不确定时，结果的**分布** |
| 敏感性扫描 | **单个**参数变动时，结论在哪个点翻转 |

先用前者定位"哪个参数影响最大"（粗），再用后者精扫那个参数（细）。
