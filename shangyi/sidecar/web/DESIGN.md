## 对照与适配

| 区域 | Onyx 参考 | 商奕实现 |
|---|---|---|
| 左栏 | 品牌、会话入口、agent、历史列表 | 商奕、咨询入口、经营主题、真实历史咨询 |
| 中部 | 用户问题、无外框助手正文 | 历史决策问题、建议与理由，完整报告按需展开 |
| 右栏 | 来源列表、引用、文档详情 | 成功检索记录、理论资料、模型参数与溯源 |
| 底部 | 圆角输入框、轻量工具行、发送按钮 | 新咨询背景问答；历史页明确显示另开咨询入口 |
| 色彩 | 近白底、灰色侧栏、弱边框、局部蓝色 | 相同层次，移除原页面品牌渐变及循环装饰动画 |
| 信息密度 | 小字号导航、独立滚动、正文留白 | 224px 导航、296px 证据栏、正文最大 724px |
| 窄屏 | 按空间切换侧栏呈现 | 950px 以下证据抽屉；680px 以下导航抽屉 |

本实现的尺寸是适应中文与现有容器的明确设计值，不冒称从截图精确测量。做过浏览器视觉对照，但没有像素差异计量，因此不宣称 100% 像素一致。

业务适配：
- Onyx 自由对话在现有商奕后端里没有等价能力。新的输入区使用现有剧本背景问答，逐题回答、允许跳过、回看修改，再提交。
- 历史页没有伪装的“继续对话”输入框，提供明确的“新建同类咨询”入口。
- 网页仍通过现有自动确认运行通道。启动前必须明确选择自动分析，中途三个检查点不会等待网页人工确认。
- 背景问答是既有主题清单，不冒充模型实时追问；浏览器草稿仅保存在当前 sessionStorage。
- 来源面板将理论资料与经营事实区分。原记录的建议和置信度原样呈现，不新增事实或重算结论。

## 已实施

- 替换应用壳、侧栏、顶栏、正文布局、证据面板、输入区与移动端抽屉。
- 新咨询采用逐题输入、选项快捷回答、暂不清楚、上一题、提交前逐项更正。
- 咨询列表支持关键词与模式筛选，以及空结果状态。
- 历史页展示原建议、原理由、限制、模型与报告，支持复制建议、导出完整原始 JSON。
- 运行页区分正在运行、正常退出、非零退出，提供停止操作和可展开日志。
- 推演台继续使用真实离线引擎；输入修改后旧结果失效；计算返回时检查输入版本。
- 修正背景问题解析漏掉每组最后一题，按 CLI 优先级读取本机覆盖的剧本。
- 新版页面检查后端 frontend_contract=2，旧进程不能静默使用不匹配的问题清单。
- 路由为每次挂载创建独立节点，防止较慢的旧请求覆盖新页面。
- 原有 Tabler 只保留兼容网格与领域组件的基础样式，应用外壳由新样式定义。

## 已知边界

- 不支持历史会话续聊和网页中途人工检查点确认，这是后端交互通道边界。
- 预答仍按 CLI 所要求的题目顺序传递。若模型不遵循剧本顺序，前端无法替代引擎完成按问题 ID 的绑定。
- 当前网页不接受文件上传，也没有语音输入；没有展示无实现的同名按钮。
- 运行注册表仍是服务进程内存，服务重启后只能从历史咨询查看已落盘产物。
- 手机验证使用模拟视口，没有声称在物理手机上测试。
- 引擎业务数值与历史建议未因本次视觉重构改变。
